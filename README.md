# Lista de tarefas simples

Aplicação de to-do list sem instalação e sem banco de dados. As tarefas ficam salvas no `localStorage` do navegador.

## Ver localmente

Abra o arquivo `index.html` no navegador ou use qualquer servidor estático.

Ao abrir, basta clicar em **Entrar**. Depois você pode adicionar, concluir e excluir tarefas.

## Publicar

O projeto é estático e pode ser publicado diretamente no GitHub Pages, Netlify ou Vercel.
